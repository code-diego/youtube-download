# Guía de como usar

## instalar libreria pytube

```bash
pip install pytube
```
## ajecutar programa

Para descargar un link a mp3
```bash
python yt-link-to-mp3.py
```
Para descargar un link a mp4
```bash
python yt-link-to-mp4.py
```
Para descargar un link(palylsit) a mp3(palylist)
```bash
python yt-playlist-to-mp3.py
```
